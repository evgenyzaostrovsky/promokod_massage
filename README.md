# VIP-доставка

Мобильный устанавливаемый лендинг с обратным отсчётом до полуночи по московскому времени.

Разместите файлы на статическом HTTPS-хостинге. На iPhone откройте сайт в Safari, нажмите «Поделиться» → «На экран Домой».

## Telegram-уведомления

API-функция `api/notify.js` рассчитана на Vercel. В настройках проекта добавьте переменные окружения:

- `TELEGRAM_BOT_TOKEN` — токен от BotFather;
- `TELEGRAM_CHAT_ID` — ID чата, куда бот будет присылать уведомления.

Токен нельзя добавлять в исходный код или коммитить в GitHub.
